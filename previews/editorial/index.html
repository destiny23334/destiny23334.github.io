用 GitHub Pages 免费托管自己的站点

2026 年 11 月 20 日 · 技术 · 8 分钟

GitHub Pages 是 GitHub 自带的静态站点托管服务。把一个仓库推上去，它就会把里面的 HTML 当成网站对外提供访问——免费、支持 HTTPS，也不需要服务器。

两种仓库，两种地址

取决于仓库名，Pages 给你的域名不一样：用户名.github.io 是用户站点，访问裸域名；其他仓库名则是项目站点，地址后面会多一段路径。

静态托管意味着没有服务端逻辑。需要接口、表单提交、评论时，接第三方服务或者换个部署方式。

开启 Pages

git init
git add .
git commit -m "init blog"
git push -u origin main

保存后等一两分钟，页面顶部会出现访问地址。之后每次 git push 都会自动重新发布。
