用 GitHub Pages 免费托管自己的站点

2026.11.20技术8 min read

GitHub Pages 是 GitHub 自带的静态站点托管服务。把一个仓库推上去，它就会把里面的 HTML 当成网站对外提供访问——免费、支持 HTTPS，也不需要服务器。

两种仓库，两种地址

用户站点要求仓库名是 用户名.github.io，访问裸域名；其他仓库名则是项目站点，地址后面多一段路径。

静态托管意味着没有服务端逻辑。需要接口、表单提交、评论时，接第三方服务或者换个部署方式。
