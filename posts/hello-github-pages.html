用 GitHub Pages 免费托管自己的站点

2026.11.20 技术 GitHub 8 min read

GitHub Pages 是 GitHub 自带的静态站点托管服务。把一个仓库推上去，它就会把里面的 HTML 当成网站对外提供访问——免费、支持 HTTPS，也不需要服务器。

两种仓库，两种地址

取决于仓库名，Pages 给你的域名不一样：

  • 用户站点：仓库名必须是 用户名.github.io，访问地址是 https://用户名.github.io。
  • 项目站点：任意仓库名，访问地址是 https://用户名.github.io/仓库名。

想当个人主页用，直接建用户站点最省事。已经有同名仓库的话，它会变成主页，需要注意别覆盖。

开启 Pages

  1. 仓库 Settings → Pages。
  2. Source 选 Deploy from a branch，分支选 main，目录选 / (root)。
  3. 保存，等一两分钟，页面顶部会出现访问地址。

首次部署通常要等半分钟左右，之后每次 git push 都会自动重新发布。改动没生效时先看仓库的 Actions 或 Environments 里最新的部署记录。

几个容易踩的坑

  • 路径大小写：GitHub 的服务器区分大小写，本地 Windows 不区分。本地能打开的 Assets/CSS/style.css，线上可能 404。
  • 以路径访问：首页必须是仓库根目录的 index.html，否则访问域名会看到 404。
  • 下划线开头的文件：默认会走 Jekyll 处理，可能被忽略。放进一个空的 .nojekyll 文件即可关掉。

绑定自己的域名

在 Pages 设置里填 Custom domain，然后到域名服务商加一条 CNAME 记录指向 用户名.github.io。开启 HTTPS 后等证书签发完成就行。

静态托管意味着没有服务端逻辑。需要接口、表单提交、评论时，接第三方服务或者换个部署方式。
